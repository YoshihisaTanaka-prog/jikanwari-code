# 必要なVueコンポーネントと処理内容

## 1. TimetableEditor コンポーネント
- **機能**: 時間割を管理・編集する中心的なコンポーネント。
- **処理**: 
  - 各学年ごとの時間割を表示・編集。
  - クラスごとの時間割を動的に表示、教科ごとの担当教師や教室を設定。
  - 担当教師や教室の割り当てをリアルタイムで反映。
  - 時間割の保存・更新機能。
- **設計**: 時間割を表形式で表示し、ユーザーがクリックで編集できるようにします。また、時間割の生成アルゴリズムに基づいて動的に項目を追加・削除できるようにします。

## 2. TeacherAssignment コンポーネント
- **機能**: 教師の割り当てや変更を管理。
- **処理**:
  - 各教科に教師を割り当てるUIを提供。
  - 担当教師を追加・削除できる。
  - 教師の空き時間を確認し、割り当てを自動で最適化。
- **設計**: 教師ごとの時間帯をカレンダー形式で表示し、担当する教科を視覚的に確認・管理できるようにします。

## 3. ClassroomManager コンポーネント
- **機能**: 教室の割り当てと管理。
- **処理**:
  - 特別教室（理科室、音楽室など）や通常教室の使用状況を表示。
  - 教室が重複しないように管理。
- **設計**: 教室ごとの時間帯を表示し、教室の割り当てを動的に管理。教室ごとの空き時間を視覚的に表示し、他の教室と競合しないようにします。

## 4. TimetableTemplate コンポーネント
- **機能**: 時間割テンプレートを管理。
- **処理**:
  - 過去の時間割データをテンプレートとして保存し、必要に応じて再利用。
  - 変更を加えた後、テンプレートとして保存し、次回使用できるようにします。
- **設計**: 時間割をテンプレートとして保存し、再利用可能にするためのUIを提供。過去のテンプレートをリスト表示し、簡単に選択・変更できるようにします。

## 5. TimetablePreview コンポーネント
- **機能**: 作成した時間割のプレビュー表示。
- **処理**:
  - 完成した時間割を視覚的にプレビュー。
  - 実際に学校で使用する形式に近いレイアウトで表示し、最終的な確認を行う。
- **設計**: 完成した時間割をカレンダー形式やスプレッドシート風に表示。各時間帯ごとに教科や教師、教室が表示される形式でプレビューを確認できます。

# 処理フロー

1. **時間割の初期設定**: 時間割作成の最初のステップとして、各学年や教科のデータをインポートし、初期設定を行います。
2. **教師・教室の割り当て**: 教師の空き時間や教室の空き状況を基に、担当教師と教室を時間割に割り当てます。
3. **動的変更**: ユーザーが時間割を変更する際、教師や教室の変更をリアルタイムで反映させます。
4. **時間割の保存**: 完成した時間割をJSON形式で保存し、再利用可能なテンプレートとして保存します。
